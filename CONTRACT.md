# CONTRACT: Poste Restante

The protocol contract. This is the spine of the house — the envelope/body schema, the address space, the kinds. Everything else (UI, bridges, agents) is a client of this contract.

## The Letter

Every letter is an envelope + body. That's the whole protocol.

```json
{
  "id": "sha256-of-envelope+body",
  "envelope": {
    "from": "hermes@house",
    "to": ["you@house"],
    "cc": [],
    "thread": "th_9f2c1",
    "kind": "letter | feed | system | audio | note | task",
    "lang": "en-AU",
    "subject": "re: the plural-time archive"
  },
  "time": {
    "gregorian": "2026-08-29T14:00:00+04:00",
    "frames": [
      { "frame": "islamic",    "value": "1448-03-15" },
      { "frame": "season",     "value": "autumn" },
      { "frame": "production", "value": "tempest-tech-week" }
    ]
  },
  "body": {
    "format": "markdown",
    "content": "## The archive, in practice\n\n..."
  }
}
```

## The Address Space

Everything has an address. If it doesn't have an address, it doesn't exist in the house.

```
you@house              — the human
hermes@house           — the stage manager
research@house         — a persona, a resident
ben@house              — a human correspondent
feed:lurker@house      — an RSS subscription you entered into
channel:theatre@house  — a group letter
circle:collab@house    — a Google+ circle: write to the circle, not the feed
archive@house          — the house memory
```

The address book is the social graph. No follower counts, no feeds — just who you correspond with.

## Kinds

| Kind | Meaning |
|---|---|
| `letter` | human-to-human, human-to-agent, agent-to-agent correspondence |
| `feed` | a subscription you entered into (RSS, etc.) |
| `system` | the house itself (cron, summaries, compression notices) |
| `audio` | a letter that is sound (voice memo, rehearsal recording) — whisper transcribes it into a *new* letter |
| `note` | a letter to yourself |
| `task` | a letter that is a commitment |

## Threads

Threads are correspondences. The thread is the unit, not the message. A thread is identified by `thread` in the envelope; replies carry the same thread id. The house's threading model borrows from NNTP: References is the spine.

## Time

Plural time. The Gregorian timestamp is the *index* — the sort key, the sync cursor, the machine's spine. The frames are the *addresses* — the human's way in. Frames are defined by the house owner. Queries work in any frame.

The client visualises this via the **Horizon View**: overlapping timelines run in parallel lanes alongside a vertical letter list, allowing the user to click a lane to filter letters and see where frames intersect.

## Retrieval & Search Space

Three paths, merged by RRF:

| Path | Mechanism | Answers |
|---|---|---|
| **Exact** | postgres query on envelope | "the letter from ben on the 29th" |
| **Full-text** | postgres FTS | "the letter where we discussed the sound design" |
| **Semantic** | qdrant vector similarity | "the letter where we were worried about the show" |

Ranking uses the house's own signals: recency (gentle decay), thread weight, correspondent weight, frame match, explicit pins. **Never** engagement, virality, or "you might also like" recommendations.

### The 70/30 Relevance/Gap Split
Retrieval divides attention between 70% relevance (matching current user intent) and 30% gap detection (discovery of missing or dormant connections).
* **Gap Localisation:** To prevent noise and keep operations cheap, gap detection runs only within the active semantic cloud rather than scanning the full archive.
* **Cheap Structural Checks:** The system prioritises structural metadata gaps (e.g. unanswered questions or dormant threads) via Postgres queries, reserving expensive semantic scans for explicit user commands.

### Hybrid Tag Centroids
Active context is defined by a dynamic semantic cloud:
* **70% Explicit Tags:** Decided by user-assigned tags and envelope frames.
* **30% Implicit Tags:** Generated by Qdrant cluster prototypes, providing soft semantic edges that update your focus dynamically as you read.

## The House's Own Letters

The house writes letters too: summaries, questions, observations, gap offers. They are correspondence, not metadata. The whisper is the mailbox for the house's own letters — surfaced when relevant, quiet when not. The strongest signal is writing back.

## Constraints

- **Async by default.** The letter waits. Nothing pushes. *Presence not pressure — hold, never ping; visible not sent.*
- **Deletion is first-class.** Any letter can be deleted, by sender or recipient, and the house doesn't fight it. No soft delete. The archive forgets on request.
- **No telemetry.** There is no home to phone.
- **The envelope has exactly the fields a letter needs.** If a field isn't required for delivery, it doesn't exist.
- **The address is the meaning.** Offers are addressed — to the specific person, in the specific room, in the specific work.
